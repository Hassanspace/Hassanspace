### About

I'm a software engineer who works across the stack — from training a computer vision model to shipping the interface someone actually uses. My background is in **AI/ML and computer vision**, built alongside professional experience in **Django and React**, so I'm equally comfortable in a notebook and in a production codebase.

I enjoy engineering most when a system has to work in real time, in front of a real user — a live video feed being scored frame by frame, not a static demo. That's the kind of problem I keep gravitating toward. I'm currently drawn to teams building applied AI products: developer tools, computer vision systems, and software where the model is one part of a much larger engineering problem.

### Featured Projects

**AI Fitness Trainer** — *Computer Vision, Deep Learning*
Real-time system that analyzes live webcam video to evaluate gym exercise posture and returns corrective feedback as the user moves.
- **Problem solved:** most people can't self-check exercise form without a trainer in the room
- **Tech:** Python, TensorFlow, PyTorch
- **Key features:** live video pipeline, pose detection and classification, instant feedback loop
- **What I learned:** the hard part of real-time CV isn't the model — it's keeping the whole pipeline fast enough to feel instant
- [GitHub](https://github.com/Hassanspace)

**SYNAP STUDY** — *AI Academic Platform, Final Year Project*
Full-stack academic platform combining chat moderation and ML-based learning assistance for students.
- **Problem solved:** students needed a moderated, assisted platform for academic collaboration, not just a plain forum
- **Tech:** React, Django, Python (ML modules)
- **Key features:** chat moderation system, ML-driven learning assistance, full-stack architecture
- **What I learned:** integrating an ML feature into a live product is a different discipline than training the model itself
- [GitHub](https://github.com/Hassanspace)

**AI StoryBook Generator** — *NLP, Generative AI*
Generates personalized storybooks from user-provided characters, themes, and story ideas, output as formatted, downloadable PDFs.
- **Problem solved:** turning unstructured user input into a coherent, readable narrative automatically
- **Tech:** Python, NLP, Generative AI
- **Key features:** narrative structuring pipeline, dynamic PDF generation, per-user personalization
- **What I learned:** generative output needs as much structure and constraint-design as it needs creativity
- [GitHub](https://github.com/Hassanspace)

**Streaming Website** — *AI Recommendation System*
Netflix-style streaming platform with full authentication and an AI-based recommendation engine for content discovery.
- **Problem solved:** static content catalogs don't help users find what they'll actually want to watch
- **Tech:** React, Django, Recommendation Engine
- **Key features:** end-to-end auth flow, personalized recommendations, full-stack architecture
- **What I learned:** recommendation quality is only half the product — the surrounding UX decides if it gets used
- [GitHub](https://github.com/Hassanspace)

**Architecture Portfolio Website** — *Brand-Driven Web Platform*
Dual-audience portfolio site for an architecture firm, built around a full brand system with routing designed separately for B2B firms and B2C homeowners.
- **Problem solved:** one audience wanted credibility signals, the other wanted inspiration — a single generic layout served neither well
- **Tech:** Next.js, Tailwind CSS, Framer Motion
- **Key features:** dual-audience information architecture, custom typography and color system, motion-driven interactions
- **What I learned:** brand strategy isn't a design afterthought — it changes the technical structure of the site itself
- [GitHub](https://github.com/Hassanspace)
